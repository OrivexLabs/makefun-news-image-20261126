A pure-stdlib Python program that draws one 1024x1024 PNG summing up the world news of Thursday 26 November 2026 as a newspaper front page: ten stories, from the US unveiling sweeping new tariffs and the Thanksgiving storm grounding the 100th Macy's parade, to the Houthi strike on Saudi Arabia's largest refinery, Ukraine hitting a Russian air base, Kim Jong Un's tactical-nuclear order, the Wall Street AI rout, the FCC clearing SpaceX's million-satellite Starmind constellation, the Cairo tanker fire, the Gulf plane crash, and Colombia freeing 76 hostages. No third-party libraries: a hand-written PNG encoder, a 5x7 bitmap font, and procedural pictograms, so the output is byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
